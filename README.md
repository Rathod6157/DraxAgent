# DraxAgent 🤖

> An AI Desktop Companion that lives alongside you — observes, remembers, and grows with you.


## What is DraxAgent?

DraxAgent isn't just another AI chatbot. It's a modular AI companion 
designed to observe your desktop activity, remember context, and 
proactively assist you as you work.

## ✨ Current Features

- 🖥️ **Desktop Awareness** — Detects what apps you're using in real-time
- 🧠 **Working Memory** — Remembers conversations across the session
- 🎯 **Intent Classification** — Understands whether you want a chat or an action
- ⚡ **Skill System** — Executes desktop actions through natural language
- 🔀 **Compound Command Handling** — Handles multi-part requests in one message
- 💬 **Personality System** — Consistent character across all interactions
- 🎨 **Clean GUI** — PyQt-based chat interface with threading
